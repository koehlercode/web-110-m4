## Sneaker Hut
A simple HTML and CSS practice project that demonstrates basic webpage structure, navigation, typography, links, colors, and CSS selectors.

# Files
`index.html` — Contains the webpage structure, including the header, navigation menu, and content section.
`style.css` — Contains the styling for layout, typography, colors, navigation links, hover/active states, and paragraph classes.

# Features
- Semantic HTML structure
- Custom Google Font (Lato)
- Styled navigation menu
- Link hover and active states
- Custom typography and text styling
- CSS class selectors
- Basic color and spacing customization
